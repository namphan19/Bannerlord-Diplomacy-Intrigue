# tools/Localize - the methods outside UI/ whose return value a player reads.
#
# One rule per line:  <file> | <method> | <why a player reads it>
#
# Most player-facing text lives under src/DiplomacyIntrigue/UI/, because that is where the mod
# draws. What is left belongs to the system that computes it: a band's name, a hold term's chip,
# the meaning of a peace term. Those values reach no engine sink of their own - a view model
# binds them straight into a property - so nothing but this list can say they are text.
#
# That is why the list is written out rather than guessed from method names. A name heuristic
# ("anything called Describe") swept in AI reasoning strings that only ever reach the log
# (Missions.ApplyEffect's "why", AiEspionage.BestInBand's out parameter), and a wrong conversion
# is a wrong English string on a player's screen. The list was built by asking the other way:
# every Type.Method call made from UI/ whose return type is string or TextObject.
#
# A text-producing method that is missing here shows up in the report as "not a screen", which is
# the AC3 audit's worklist (story 4.1 §5 AC3): an English sentence a player can see.
